In short

  • Kelly Tools For Revit, version 5 took 62% of the work (338 issues). The add-in was split into a small host and six ribbon-tab modules, its direct connection to SQL Server was removed so every machine reads the same shared data files, and the field tools got a broad defect sweep.
  • Component Data Editor is a new desktop application (57 issues) that replaces the Access front end for editing the fabrication component catalog. It was published to its users, and a web edition has started.
  • Shared libraries under both versions (110 issues) got corrected numbering and geometry rules, and database code was separated into its own packages for CSV, JSON, SQLite and SQL Server.
  • Version 4 (23 issues) now installs beside version 5 in its own folder, so either version can be used on a machine.
  • Nearly 60% of the closed work is Change or Delete: restructuring and removing old code so new features cost less. Fixes and new features make up most of the rest (36%).

What each product line delivered

Kelly Tools For Revit 5

338
KTR5 205 · Revit Logic 5 101 · Revit UI 32 · 527 points
  • Rebuilt as a host that loads six ribbon tabs as separate modules (All Trades, Pipe, Duct, Contenter, Manager, Developer), so one tab can change without touching the others.
  • No longer connects to SQL Server: it loads the shared data files at startup, and Reload Data refreshes them without restarting Revit.
  • New Assigners pane: Add All and Remove All for every context on a selection, Inherit All from a picked element, and Auto-Assign for added contexts.
  • Defects fixed in field tools: Layout Point Export and Import, Spool Creator and Spool Manager, Racker, Suspended Support Manager, Duct Item Number Set. Two of them could lose saved points or commit partial edits.
  • Updaters no longer overwrite a user's own Service Signature edit or show a prompt while Revit is updating the model.
  • A startup check confirms every application service started, and long operations show a progress window with the time remaining.

About the numbers
  • Source: Linear workspace "Kelly Tools For Revit", every issue completed between 17 September and 17 November 2026 (541), plus the open issues in a started state on 17 November (27). Canceled issues are not counted.
  • Product lines group the Linear teams: version 5 is KTR5, KTRL5 and KTRUI; shared libraries are KD, KW3, KWD3, KWDC, KWDJ, KWDSL and KWDSS; the Component Data Editor is CDE, CDED, CDEC and CDEB.
  • Story points use an exponential scale (1, 2, 4, 8, 16). Estimating started on 9 November, so 215 earlier issues carry no points and the 799 total is a floor.
  • "Other" areas combine Content and parameters, Planning, Views and graphics, Domain types, Spools and welds, General, and 4 issues with no area label. "Untyped" is 28 older version 5 issues filed before type labels existed.
